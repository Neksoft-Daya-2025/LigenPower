# 🚀 Ligen Dealer Locator - Full Laravel Application

## 📁 Upload Structure
Upload ALL contents of this folder to: `public_html/merchant/`

## 🌐 Subdomain Setup
1. Create subdomain: `merchant.ligenpower.com`
2. Point to: `public_html/merchant/`
3. Select PHP 8.2

## 📋 File Permissions
Set these in Hostinger File Manager:
- All folders: **755**
- All files: **644**
