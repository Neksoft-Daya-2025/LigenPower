A standalone HTML website - ready to edit and use!

## How to Use

### View the Website
- Simply double-click `index.html` to open in your browser
- Or right-click → Open with → Your browser

### Edit the Website
- **HTML Content:** Edit `index.html` in any text editor
- **Styles:** Edit files in `assets/css/`
- **Functionality:** Edit files in `assets/js/`
- **Images:** Replace files in `assets/images/`

## Features

✅ Fully standalone - works offline  
✅ All assets included locally  
✅ No server needed  
✅ Easy to edit

1. Open `index.html` in your browser to view
